# Vertronics Resources

Free engineering resources from [Vertronics](https://www.vertronicstech.com/resources/): open textbooks, study modules and hand-picked open-source tools for hardware, embedded and automation work.

No sign-up. Browse the folders below, or use the [Resources page](https://www.vertronicstech.com/resources/) for search and filters. Folder names match the categories on the website.

| Folder | What's inside |
|---|---|
| [`reference-library/`](reference-library/) | Open textbooks (PDF) |
| [`student-hub/`](student-hub/) | Short study modules (PDF) and free courses |
| [`tools/`](tools/) | Open-source design tools (links) |
| [`blueprints/`](blueprints/) | Firmware and automation frameworks (links) |
