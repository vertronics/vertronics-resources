# Blueprints

Proven foundations to build firmware and automation on. Each is a Vertronics copy (GitHub fork) of the original, kept with its original licence and credits. For security fixes, check the original project first.

| Project | What it is | Licence |
|---|---|---|
| [FreeRTOS kernel](https://github.com/vertronics/FreeRTOS-Kernel) (original: [FreeRTOS/FreeRTOS-Kernel](https://github.com/FreeRTOS/FreeRTOS-Kernel), FreeRTOS (Amazon)) | Small real-time operating system for microcontrollers | MIT |
| [Zephyr](https://github.com/vertronics/zephyr) (original: [zephyrproject-rtos/zephyr](https://github.com/zephyrproject-rtos/zephyr), Zephyr Project (Linux Foundation)) | Full RTOS with drivers, networking and security | Apache-2.0 |
| [ESP-IDF](https://github.com/vertronics/esp-idf) (original: [espressif/esp-idf](https://github.com/espressif/esp-idf), Espressif Systems) | Official framework for ESP32 chips | Apache-2.0 |
| [TensorFlow Lite Micro](https://github.com/vertronics/tflite-micro) (original: [tensorflow/tflite-micro](https://github.com/tensorflow/tflite-micro), Google (TensorFlow)) | Machine learning on microcontrollers | Apache-2.0 |
| [Node-RED](https://github.com/vertronics/node-red) (original: [node-red/node-red](https://github.com/node-red/node-red), OpenJS Foundation) | Visual wiring of sensors, APIs and automation flows | Apache-2.0 |
