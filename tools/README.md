# Tools

Open-source design tools. Each is a Vertronics copy (GitHub fork) of the original project, kept with its original licence and credits. The original authors maintain the projects; use **Sync fork** on GitHub to bring a copy up to date.

| Project | What it does | Licence |
|---|---|---|
| [KiKit](https://github.com/vertronics/KiKit) (original: [yaqwsx/KiKit](https://github.com/yaqwsx/KiKit), Jan Mrázek) | Panelises KiCad boards and automates fabrication output | MIT |
| [InteractiveHtmlBom](https://github.com/vertronics/InteractiveHtmlBom) (original: [openscopeproject/InteractiveHtmlBom](https://github.com/openscopeproject/InteractiveHtmlBom), openscopeproject) | Interactive, clickable bill of materials for assembly | MIT |
| [SKiDL](https://github.com/vertronics/skidl) (original: [devbisme/skidl](https://github.com/devbisme/skidl), Dave Vandenbout) | Describe circuits in Python instead of drawing them | MIT |
| [PlatformIO](https://github.com/vertronics/platformio-core) (original: [platformio/platformio-core](https://github.com/platformio/platformio-core), PlatformIO Labs) | One build system for many microcontroller families | Apache-2.0 |
