# Tools

Open-source design tools. Links only; each project is maintained by its own authors.

| Project | What it does | Licence |
|---|---|---|
| [KiKit](https://github.com/yaqwsx/KiKit) | Panelises KiCad boards and automates fabrication output | MIT |
| [InteractiveHtmlBom](https://github.com/openscopeproject/InteractiveHtmlBom) | Interactive, clickable bill of materials for assembly | MIT |
| [SKiDL](https://github.com/devbisme/skidl) | Describe circuits in Python instead of drawing them | MIT |
| [tracespace](https://github.com/tracespace/tracespace) | View Gerber and drill files in the browser | MIT |
| [PlatformIO](https://github.com/platformio/platformio-core) | One build system for many microcontroller families | Apache-2.0 |
| [awesome-electronics](https://github.com/kitspace/awesome-electronics) | Curated list of electronics resources | CC0-1.0 |
